# Support

## Before opening a report

1. Update to the latest extension preview and run `cmd update`.
2. Confirm `cmd --version` is 1.15.0 or newer in the same local or remote environment as VS Code.
3. Run `cmd status` and verify the account is authenticated.
4. Run **CommandDock: Copy Redacted Diagnostics** and review the result before sharing it.

Never include prompts, source code, credentials, access tokens, `.env` contents, or raw Command Code history unless you have intentionally removed sensitive data.

## Channels

- CommandDock installation and UI issues: [CommandDock issues](https://github.com/gmalbert/command-dock/issues)
- Command Code CLI and account issues: use the support channel identified in the upstream Command Code documentation.
- Documentation: [commandcode.ai/docs](https://commandcode.ai/docs)
- Community help: [Command Code Discord](https://commandcode.ai/discord)
- Security vulnerabilities: submit a private report through [SECURITY.md](SECURITY.md), not public issues.

Include OS, architecture, VS Code version, local/WSL/SSH/container context, extension version, CLI version, reproduction steps, expected behavior, actual behavior, and reviewed redacted diagnostics.

Public preview support is best-effort. Confirmed security reports are acknowledged within two business days; see the security policy for response targets.
